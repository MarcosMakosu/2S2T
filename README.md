## 📖 Visão Geral

SSTT é um jogo de corrida estilo kart desenvolvido na **Godot Engine 4.x**.  
Você controla um tuktuk, usa poderes especiais, pula obstáculos.

---

## 🎮 Funcionalidades Planejadas (MVP)

- [ ]  **Menu principal** (início, opções, sair)
- [ ]  **Sistema de personagens**
  - [ ] 3 personagens jogáveis com seus tuktuks
  - [ ] Demais personagens → IA baseada em **seed** (comportamento previsível)
- [ ]  **Uma pista** jogável, ao menos
 - [ ] **Sistema de upgrade de status** (velocidade, aceleração, controle)
- [ ] **Modo história** – primeira pista como introdução narrativa

---

## ⚙️ Mecânicas de Jogo

### 🎲 Poderes e “Active Blocks"
- Cada tuktuk carrega **até 3 poderes fixos**.
- Itens na pista ativam **aleatoriamente um desses poderes** (e não um poder genérico).

### 🦘 Pulo
- Tuktuk pode pular! Usado para desviar de ataques ou obstáculos.
